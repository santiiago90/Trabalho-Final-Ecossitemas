# Sistemas Numéricos com Flask

Projeto desenvolvido em Python com Flask para:

- Conversões entre sistemas numéricos
- Operações binárias
- Operações hexadecimais
- Geração de tabelas Gray

## Tecnologias

- Python
- Flask
- HTML
- CSS

## Como executar

Instalar dependências:

```bash
pip install -r requirements.txt
```

Executar:

```bash
python app.py
```

Abrir no browser:

```txt
http://127.0.0.1:5000
```
